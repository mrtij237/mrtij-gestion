# Mr TIJ Gestion

Application installable (PWA) pour les proformas, reçus d'acompte, reçus finaux et le suivi des paiements de Mr TIJ. Elle fonctionne sans connexion une fois installée ; les données restent sur chaque appareil.

Adresse : https://mrtij237.github.io/mrtij-gestion/

- Android / PC (Chrome, Edge) : menu ⋮ → « Installer l'application ».
- iPhone / iPad (Safari) : Partager → « Sur l'écran d'accueil ».
